# 대시보드 배포 가이드 (무료, 설치 불필요)

목표: 이 폴더의 파일들을 인터넷에 올려 **누구나 접속 가능한 링크**를 만든다.
링크를 기획서에 첨부하면 = 결과물 제출 + 심사위원 직접 체험 가능.

소요 시간: 약 15~20분. 프로그래밍 지식 필요 없음 (드래그 & 클릭).

---

## ⚠️ 시작 전 — Groq 키 재발급 (중요)
지금 키는 채팅에 노출됐고, 배포하면 더 많은 사람이 쓰게 돼. **새 키로 바꾸세요.**
1. console.groq.com → API Keys → 기존 키 삭제 → **Create API Key** → 새 키 복사
2. 이 새 키를 아래 **2단계 4번**의 Secrets 칸에 입력 (파일에는 넣지 않음)

---

## 1단계: GitHub에 파일 올리기

GitHub = 코드를 인터넷에 보관하는 무료 사이트.

1. github.com 가입/로그인
2. 우측 상단 **+** → **New repository**
3. Repository name 입력 (예: `jaeseonchung-dashboard`) → **Public** 선택 → **Create repository**
4. 다음 화면에서 **"uploading an existing file"** 링크 클릭
5. 이 **`배포용` 폴더 안의 파일 6개**를 화면에 드래그 (아래 목록):
   - app.py
   - decision_tools.py
   - agent.py
   - sgg_names.py
   - requirements.txt
   - 재선충_ML학습데이터셋_2016_2023.csv
6. 아래 **Commit changes** 버튼 클릭

> ⚠️ `.env` 파일은 **올리지 마세요** (배포용 폴더엔 아예 없으니 안심). 키는 5단계에서 따로 넣습니다.

---

## 2단계: Streamlit Cloud로 배포

1. **share.streamlit.io** 접속 → **Continue with GitHub** (GitHub 계정으로 로그인)
2. **Create app** → **Deploy a public app from GitHub** 선택
3. 설정:
   - Repository: 방금 만든 저장소 선택
   - Branch: `main`
   - Main file path: `app.py`
4. **Advanced settings** 클릭 → **Secrets** 칸에 아래 한 줄 입력 (새 키 사용):
   ```
   GROQ_API_KEY = "gsk_여기에_새로_발급한_키"
   ```
5. **Deploy** 클릭 → 2~5분 기다리면 완료
6. 생성된 주소(`https://....streamlit.app`)가 **제출용 링크**입니다.

## 문제 발생 시
- 화면에 빨간 에러가 뜨면 메시지를 캡처해서 알려주세요.
- 대부분 ① Secrets 키 오타 ② 파일 누락 ③ 패키지명 오타 입니다.
- 앱이 "잠자기" 상태가 되면(며칠 미사용) 접속 시 깨어나는 데 30초쯤 걸립니다 — 정상입니다.
